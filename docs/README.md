# Ryver Docs

This directory stores the project vision and early design notes.

Start here:

- `product-definition.md`: what Ryver is and what it is not;
- `ci.md`: pull request and main branch quality checks;
- `values.md`: principles that should guide tradeoffs;
- `roadmap.md`: staged implementation plan;
- `architecture.md`: initial technical direction;
- `model-driven-design.md`: codemod, visual editor, LLM, and cross-language design notes;
- `prior-art.md`: systems to study;
- `open-questions.md`: unresolved design questions.
